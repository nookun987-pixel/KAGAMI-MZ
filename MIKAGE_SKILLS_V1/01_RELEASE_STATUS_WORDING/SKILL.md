# Release Status Wording

## Purpose

Prevent wrong caption and link wording. Release wording must match confirmed status, not assumptions.

## Rules

Use:

- If `live_confirmed = YES`: `Listen now:`
- If `release_date_future = YES`: `Pre-save:`
- If `status_uncertain = YES`: `Link:`

Never use:

- `Pre-save / listen`
- `Pre-save/listen`
- `Listen now:` for a track that is only delivered but not confirmed public/live/searchable.

## Confirmation Standard

Do not call a track live unless a source confirms live/public/listenable status.

If source confirmation is missing, mark the status as `CHUA_XAC_NHAN` and use `Link:`.

## Output Check

Before finalizing copy, scan all visible text for forbidden wording and status overclaims.
