# Short Video Format

## Purpose

Lock the Mikage short video format and prevent off-format renders.

## Format Rules

- Resolution: 1080x1920 vertical.
- Frame rate: 30fps.
- Body duration: 20-35s unless the operator specifies otherwise.
- Visual base: void-black.
- Motion language: subtle rain, static, signal, or motif movement.
- Text pacing: one text unit visible at a time.
- Main text: large and readable.
- Subtitle/support text: smaller than main text.
- End card: 3s allowed when requested or already part of the format.

## Forbidden

- Full lyric video unless the operator explicitly asks.
- Karaoke timing.
- Debug text.
- File paths.
- `SHORT` labels inside the video.
- CTA link inside the video body.
- Five subtitles on screen simultaneously.

## Verification

Check the rendered or planned output for format, text density, readable hierarchy, and absence of forbidden labels before claiming pass.
