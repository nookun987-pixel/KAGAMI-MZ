# MIKAGE_SKILLS_V1

This Skill Pack is a small set of reusable working instructions for Mikage tasks.

It is not a new agent, autonomous worker, orchestration layer, or external dependency. It is a repo-local instruction pack that any AI, Codex, or Claude tab can read before doing Mikage work.

Skills are intentionally small. Each folder contains a `SKILL.md` focused on one work pattern.

For most tasks, read these first:

1. `00_READ_FIRST/SKILL.md`
2. The relevant task skill
3. `05_CODEX_TASK_HANDOFF/SKILL.md` when creating Codex tasks

Do not invent missing data. Mark unknowns as `CHUA_XAC_NHAN`.
