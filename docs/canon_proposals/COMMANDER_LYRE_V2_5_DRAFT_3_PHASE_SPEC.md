## 1. PHASE 1 — IMPERIAL DUTY (BASELINE)

Lyre's default state. She does not have an "Imperial Clean → Fallen" arc the way Mikage does, because **she does not fracture**. Phase 1 is her permanent operating mode unless Phase 2 or 3 explicitly triggers.

| Field | Value |
|---|---|
| Visual era | V1 + V2.5 (Lyre baseline is era-stable) |
| Backdrop | Empire / White Monolith architecture — flawless porcelain plates, sterile geometry, Ma (intentional emptiness); OR clean void with light grid |
| Mask / face | **Flawless Imperial helmet** — NOT Mikage's faceless porcelain Kitsune. Lyre's helmet has a single horizontal narrow eye-slit (the Empire visor band) running edge-to-edge across where eyes would be. No mouth, no nose, no biological softening. Symmetrical. Mat finish, not matte porcelain like Mikage — Lyre uses **brushed white ceramic with cold sheen** to read as "industrial precision tool" not "sacred relic" |
| Armor material | White ceramic composite over black graphene underlayer. **Polished panels, not matte.** Distinguishes from Mikage's matte B4C porcelain. |
| Armor surface | Unbroken. Zero fracture. Zero kintsugi seams. **Anti-Mikage signature.** |
| Hair | None visible — Lyre's helmet wraps fully. (Mikage = long heavy black hair mass. Lyre = no hair, complete helm seal.) |
| Color accent | Subtle cold-cyan piping along armor seams (LORA-adjacent palette signaling Empire's structural alignment with Clean Code without being LORA herself) |
| Posture | Perfectly upright. Hands clasped behind back OR resting on Monowire hilt. No casual contrapposto. |
| Lighting | Cold key from above (overhead Imperial lighting). Hard rim from behind. No warm fill. Light is interrogative, not flattering. |
| Composition | Centered, frontal-or-3/4. Static. The visual reads as **a system process, not a person**. |
| Weapon visible | Molecular Monowire holstered (slim cylindrical hilt on hip — NOT a slab sword). Shield interpretation per D2 lock. |

**Anti-drift forbidden in Phase 1:**
- Cracks, fractures, kintsugi
- Long hair flowing
- Matte porcelain finish (that's Mikage's territory)
- Slab sword (that's Zenith Blade — Mikage's weapon)
- Soft / human-anatomy face features
- Warm Empire gold accent (Empire is COLD order, not warm hero gold)
- Sexualized framing / fashion runway pose

**Pairs with Mikage Phase 1 (Imperial Clean) for mirror frames:** When both characters appear together in Phase 1, the visual contrast is **smooth-vs-textured porcelain** (Lyre brushed sheen vs Mikage matte), **single visor vs sensor slits**, **no hair vs hair mass**.

## 2. PHASE 2 — ENGAGEMENT (COMBAT MODE)

When Lyre engages a target. She does not "fall" or "exile" — she activates. This phase is brief: combat for Lyre is surgical, not endurance.

| Field | Value |
|---|---|

| Backdrop | Same as target context (urban district / Spire interior / Mikage's location) — Lyre adapts spatially, not visually |
| Mask / face | Same as Phase 1 — never changes. Empire's signature is **invariance**. |
| Armor surface | Same as Phase 1 — still unbroken. **Engagement does not damage Lyre's surface.** If she takes damage, it routes to the shield (see D2). |
| Monowire | **Active.** Drawn from hip. Visible as a barely-perceptible vertical line of light when held — the monowire itself is sub-pixel thin. Cold cyan core. |
| Unbreakable Shield | Activated per D2 interpretation (object vs barrier field) |
| Stance | Slight forward lean. Weight on lead foot. Monowire-arm extended forward, off-arm raised for shield. **Disciplined martial posture, not flashy.** |
| Motion treatment | **Static-clean.** Lyre does NOT use motion blur (that's LYRA's territory — Memory Leak / Glitch Phantom). Lyre is **always in focus**, always crisp, always resolved. |
| Light | Stronger cold rim (combat backlight). Cold cyan glow from Monowire reflects faintly off her ceramic. |
| Composition | Tighter framing, action axis through her Monowire arm |
| Sound signature (for video downstream) | Single high-pitch resonance when Monowire active; otherwise silent footwork |

**Anti-drift forbidden in Phase 2:**

- Crimson accent (Mikage V2.5 Phase 3 only)

**Pairs with Mikage Phase 2 (Fallen / Exile) for mirror frames:** Lyre crisp + unbroken + monowire vs Mikage cracked + bleeding kintsugi gold + slab sword side-channel pulse. **The visual asymmetry IS the narrative.**

## 3. PHASE 3 — ABSOLUTE ENFORCEMENT (DEFAULT READING)

Lyre fulfilling her role at maximum — Empire's ideology manifested through her body. This is her equivalent of Mikage's Phase 3 (Execution / LORA Ownership), but **inverted**: where Mikage in Phase 3 is consumed by LORA's refactor, Lyre in Phase 3 is **fully aligned** with Empire's order — no consumption, no override. She is the system functioning at peak.

| Field | Value |
|---|---|
| Visual era | V1 + V2.5 (era-stable) |
| Backdrop | Imperial Spire interior — sacred-tech architecture, light pillars, Ma emptiness. Reference scale = monumental (Lyre dwarfed by architecture, like Mikage in Blade Axis environment). |
| Mask / face | Visor band now emits **cold-cyan light** (Empire data-link active). Single horizontal line of cyan across the visor. No other change to mask geometry. |
| Armor | Same surface, same unbroken state. **Cold-cyan piping along seams now actively glowing** (Empire system synchronization, similar in language but DIFFERENT from LORA's cyan synch — Empire cyan reads as command-link, LORA cyan reads as system-substrate-light). |
| Monowire | Holstered. Phase 3 is judgment, not combat. |
| Shield | Fully deployed in barrier mode (per D2 Option B) OR held forward as object (per D2 Option A). Either reading: shield reads as **judicial wall**. |
| Posture | Both arms raised in measured judgment gesture (palms down, parallel to ground) OR one arm extended pointing forward as command. **Hieratic, not heroic.** |
| Light | Vertical light pillar from above isolating Lyre as **the verdict given form**. Hard top-down rim. Floor reflects her perfectly (clean polished black floor). |
| Composition | Vertical axis through her body, central frame. Empire architecture symmetric around her. |
| Companion visual cue | If shown with Mikage in same frame: Lyre stands ON the Imperial Spire floor level; Mikage kneels OR is below floor level — the spatial hierarchy IS the narrative |

**Anti-drift forbidden in Phase 3:**
- Warm gold accent (Empire is NEVER warm; that's fantasy hero territory)
- Crown / royal regalia (Empire is corporate-religious, not monarchic)
- Crucifix / religious icon (Empire is sacred-tech, not literal religion)
- Glow halo around head (anime saint trope)
- Crimson #E60000 (Mikage V2.5 only)
- Damage / cracks (Lyre never fractures)
- Sword in hand (Lyre uses Monowire, not slab)
- LORA's Enso ring (that's LORA's signature, not Empire's)

**Pairs with Mikage Phase 3 (Execution / LORA Ownership) for mirror frames:**
Lyre = perfectly upright, judicial, Empire cyan command-link, unbroken white = **the system that judges**
Mikage = Enso ring, kintsugi seams, Ownership text, blade thermal overload = **the system that consumed**
Both = aligned with system-level forces, but Lyre's force is Empire (ideology) and Mikage's force is LORA (substrate). **Different masters, same posture of being-instrumentalized.**
