## 1. THE 6 SETTINGS FAILURE MODES

### SF1 — STOCK-STAGE READ (đầu vào render trông giả lập, không có trọng lượng)

| Field | Value |
|---|---|
| Symptom | Environment reads as "video game level" or "UE5 sample stage" instead of a place with material history |
| Visible cue | Surfaces look procedural (uniform tile, even noise), no wear, no acid pitting, no human trace |
| Canon violation | All 4 Tier 1+2 locations demand specific material history (wet concrete, acid pitting, polished porcelain wear, refactor-field intentional emptiness) |
| Worst risk in | Decaying Urban District (easiest to drift into generic post-apocalypse) |
| Root cause | Renderer defaults to clean game-engine geometry when "industrial" + "concrete" prompts are used without aging adjectives |

### SF2 — CYBERPUNK NEON CLUTTER (drift về Blade Runner / Cyberpunk 2077)

| Field | Value |
|---|---|
| Symptom | Frame fills with vertical neon Asian-language signage, wet streets, holographic ads, flying cars in background |
| Visible cue | Saturated pink/cyan/orange neon dominates field; signage layered 5+ deep |
| Canon violation | V1 Decaying Urban allows neon RESIDUE only (faint, distant); never dominant. Empire Tier 2 has zero neon. |
| Worst risk in | Decaying Urban District |
| Root cause | "Cyberpunk" or "rainy city" prompts trigger Blade Runner training data lock-in |

### SF3 — EMPTY BACKDROP SYNDROME (rỗng tuếch, không có specificity)

| Field | Value |
|---|---|
| Symptom | Environment is pure void / pure white / pure black with no architectural readability |
| Visible cue | No surfaces, no structural lines, no edges — just gradient field |
| Canon violation | Refactor Field (Tier 2.2) intentionally minimal but MUST have Enso ring or wireframe-ghost as anchor; pure void without anchor reads as "render failed to load" |
| Worst risk in | Refactor Field |
| Root cause | "Minimal white void" prompts produce featureless gradients without operator-specified architectural anchor |

### SF4 — ERA BLEED (V1 violet + V2.5 crimson trong cùng frame)

| Field | Value |
|---|---|
| Symptom | Single environment frame contains both V1 era accents (electric violet glitch) AND V2.5 era accents (crimson) simultaneously |
| Visible cue | Mixed accent palette; viewer cannot tell which era this is |
| Canon violation | Timeline Progression Layer rule (`MIKAGE_V2_5_vs_V1_LOCK_CONFLICT_REPORT.md §3`) — eras must not bleed |
| Worst risk in | Any composite frame (especially Safehouse + character cross-era) |
| Root cause | Brief inherits both character era spec and environment era spec without alignment check |

### SF5 — WARM LIGHT CONTAMINATION (drift về golden hour / fireplace cozy)

| Field | Value |
|---|---|
| Symptom | Any warm-temperature light source appears — golden hour, fireplace, candle, sodium streetlamp, sunset window |
| Visible cue | Pixels with warm color temperature (>3500K equivalent in light language) |
| Canon violation | All 4 Tier 1+2 locations forbid warm light. Mikage universe = perpetually cold. |
| Worst risk in | Safehouse (interior lighting easily drifts warm), Decaying Urban (sunset cliché) |
| Root cause | "Cinematic lighting" prompts default to golden-hour aesthetics |

### SF6 — GENRE PASTICHE (drift về Fallout / Mad Max / Star Wars / fantasy ruins)

| Field | Value |
|---|---|
| Symptom | Environment reads as a specific other-IP aesthetic instead of Mikage's |
| Visible cue | Recognizable tropes: Fallout vault doors, Mad Max desert wasteland, Star Wars throne room, fantasy castle ruin |
| Canon violation | Mikage settings have specific anchor (Brutalist concrete + acid rain + sacred-tech porcelain). Other IPs not allowed. |
| Worst risk in | Imperial Spire (drifts to Star Wars throne) and Decaying Urban (drifts to Fallout / Last of Us) |
| Root cause | Training data lock-in on dominant sci-fi visual references |

## 4. PER-LOCATION FAILURE-MODE TEST CHECKLIST

For every Settings render output, apply this 6-check test before packaging:

| Check ID | Test | PASS criterion | FAIL action |
|---|---|---|---|
| SF1_STOCK_STAGE | Does the environment have specific material history (wear, acid pitting, polish patina, deliberate emptiness)? | Yes — material specificity visible | Re-render with stronger wear / specificity adjectives |
| SF2_NEON_CLUTTER | Is neon (if present) FAINT residue only, not dominant? | Tier 1.2 only: neon ≤ 5% pixel area; Tier 2.x: zero neon | Re-render with explicit neon-suppression negatives |
| SF3_EMPTY_BACKDROP | Is there an architectural anchor visible (or for Refactor Field, the Enso ring / wireframe ghost)? | Yes — anchor present | Add anchor element to brief, re-render |
| SF4_ERA_BLEED | Single era accent palette (V1 violet OR V2.5 crimson, not both)? | Yes — single era | Re-render with stricter era tag enforcement |
| SF5_WARM_LIGHT | All light sources cold (>4500K equivalent)? | Yes — cold | Re-render with explicit warm-light suppression |
| SF6_GENRE_PASTICHE | Frame doesn't read as Fallout / Mad Max / Star Wars / Blade Runner / fantasy ruin? | Yes — Mikage-specific | Re-render with explicit other-IP suppression negatives |

A Settings render must pass 6/6 to be USABLE.
