## 1. /docs/mikage_master_doctrine.md

```md
# MIKAGE MASTER DOCTRINE

## 1. CORE PRINCIPLES
- Truth > Logic > Aesthetic
- Product = Untouchable
- Error = Controlled, never random
- Visual must serve commercial outcome and premium perception
- No exceptions if IP integrity is broken

## 2. INTEGRITY LOCKS
- Character Integrity: character remains 100% clean, separated from background, no contamination on body/garment/face.
- Color Integrity: Z-Blue is protected absolutely; no environmental contamination or grading shift is allowed in protected zones.
- Geometry Integrity: environment must obey classified usable geometry and distortion mapping logic.
- Narrative Integrity: the image must maintain the Clean -> Controlled Error 30-40-30 gradient.

## 3. DECISION GATE
- PASS: passes all required validation checks and is safe for production/render/shoot.
- REVISE: 1-2 recoverable non-core failures; fix and re-test from the beginning.
- REJECT: breaks IP, violates garment safety, product clarity, or commercial readability; discard frame.

## 4. ABSOLUTE FORBIDDEN
- RGB glitch / VHS degrade / random pixel noise on garment, face, or product-safe-zone.
- Any warp, melt, stretch, or edge break on garment silhouette.
- Any color shift entering protected Z-Blue region.
- Full-frame distortion with no safe zone.
- Cheap atmosphere clutter: smoke, dirt, chaotic neon spam, messy urban gimmicks.
- Distortion crossing face, weapon, logo, or primary silhouette.

## 5. ENFORCEMENT PRINCIPLE
- Same rule set must govern concept review, generation review, and runtime validation.
- A frame that fails the system must not be rescued by taste, client pressure, or artistic justification.
```

## 3. /docs/mikage_universe_visual_system.md

```md
# MIKAGE UNIVERSE VISUAL SYSTEM

## 1. VISUAL PROPOSAL
Direction: Clean Void & Geometry
- Silence instead of spectacle
- Controlled tension instead of generic sci-fi chaos
- Hyper-real central subject against a disciplined environment
- Zero cliché: no smoke, no trash clutter, no random neon overload

## 2. FRAME LOGIC 30-40-30
- 30% Context Zone (Left/Far): large urban geometry, clean or very light distortion
- 40% Product Safe Zone (Center): 100% clean, stable light, full product protection
- 30% Distortion Zone (Right/Near): strongest controlled error zone
- Mandatory gradient: Clean -> Controlled Error
- Forbidden: all-glitch frame

## 3. GEOMETRY LIBRARY
### Usable
- Flat Concrete Surface
- Corridor Line
- Metal Grid
- Glass Reflection Surface
- Parking Structure
- Wall Segmentation

### Risky
- Stair Rhythm
- Dense Shadow Pattern

### Forbidden
- Any background line cutting neck / shoulder / logo
- Any environmental color overpowering Z-Blue
- Any background that beats product hierarchy

## 4. DISTORTION MAPPING
- Lines / Corridor / Grid -> Scanline shift, perspective drift
- Surfaces / Floor / Wall -> chromatic split (light and controlled), shadow warp
- Reflection surfaces -> reflection misalignment
- Negative space / video -> temporal echo

## 5. HIERARCHY RULE
Product > Silhouette > Distortion > Background
- The image must be readable in under 1 second
- Distortion exists to create tension, not to compete for primary attention
```

## 4. /docs/mikage_character_visual_spec.md

```md
# MIKAGE CHARACTER VISUAL SPEC

## 1. CORE SILHOUETTE
- Body proportion must align with modular grid discipline
- Form must read clearly even in shadow
- Primary silhouette must remain iconic and uninterrupted

## 2. MATERIAL LAYERS
- Fabric, porcelain, graphene, chrome, and structure must read as high-end and deliberate
- Surface treatment must preserve micro-detail and avoid toy-like plastic feel

## 3. EDGE INTEGRITY
- Crisp edge separation from background is mandatory
- Rim light may define the edge but must not bloom into garment fill

## 4. PRODUCT SAFE ZONE
- Face, garment, weapon, logo = 100% clean
- No distortion, glitch, displacement, noise, or reflection contamination inside protected zones

## 5. Z-BLUE CALIBRATION
- Neutral white key protects original garment and skin values
- Z-Blue is allowed only as rim/emissive accent under system rules
- Z-Blue must not become dominant fill light

## 6. COMMERCIAL FIT
- Character and garment must read in under 1 second
- The image must be strong enough to represent IP and sell product

## 7. ABSOLUTE FORBIDDEN
- Glitch/noise directly on body or garment
- Warp on silhouette or fabric structure
- Cute/anime drift
- Plastic / PVC / toy-like surface read
- Hair/smoke/clutter breaking premium discipline
```

```md
# MIKAGE SHOT AND LIGHTING SPEC

## 1. SHOT 01 — THE SILENT RENDER
- Narrative purpose: introduce hyper-real subject against a controlled broken reality
- 30% Left: flat concrete / corridor line / clean geometry
- 40% Center: character fully clean
- 30% Right: geometry distortion attached to grid
- Anchor: garment detail + face / presence
- Allowed distortion: environmental only
- Forbidden breach: distortion entering body, messy background, cheap effects

## 2. SHOT 02 — THE ZENITH AWAKENING
- Narrative purpose: introduce lead character in infinite corridor with controlled data failure at boundary
- 30% Left: corridor line with scanline shift around 5%
- 40% Center: 100% clean, neutral white light, Z-Blue rim light
- 30% Right: reflection misalignment medium intensity mapped to glass/chrome grid logic
- Forbidden breach: cloned character reflections, Z-Blue spill into skin, distortion exceeding controlled boundary

## 3. SHOT 03 — THE SPATIAL COMMAND
- Narrative purpose: establish command over corrupted spatial parameters
- 30% Left: flat concrete + temporal echo (medium)
- 40% Center: clean subject with air-gap separation from grid effects
- 30% Right: reflection misalignment with exclusion zone away from body
- Anchor: face only
- Forbidden breach: grid touching skin or glove, broken glass crossing silhouette, two heavy distortions stacked together

## 4. LIGHTING CALIBRATION
- Key Light: Neutral White 5600K at 30-degree angle
- Rim Light: Z-Blue primary at silhouette edge only
- Ambient / Error Glow: 2-3 stops lower than key
- Air Gap Lighting: grid light must not bounce back into face/body
- Shadow Integrity: no blue contamination in facial shadow
- Silhouette Pop: subject must remain clearly separated from environment

## 5. LIGHTING VALIDATION CHECKLIST
- Z-Blue absent from facial shadow
- Rim light remains crisp edge, not fill
- Ambient/error light stays below allowed intensity
- Key light preserves fabric texture and skin tone
```

## 11. /validators/mikage_rule_engine.js

```javascript
const fs = require('fs');
const path = require('path');

function decisionFromPriority(priorities) {
  if (priorities.includes('ABSOLUTE')) {
    return { passed: false, block_level: 'ABSOLUTE', decision: 'REJECT' };
  }
  if (priorities.includes('CRITICAL')) {
    return { passed: false, block_level: 'CRITICAL', decision: 'RETRY' };
  }
  if (priorities.includes('HIGH')) {
    return { passed: true, block_level: 'HIGH', decision: 'ALLOW_WITH_FLAG' };
  }
  return { passed: true, block_level: 'NONE', decision: 'ALLOW' };
}

function loadJson(filePath) {
  return JSON.parse(fs.readFileSync(filePath, 'utf8'));
}

function evaluateRule(rule, signals) {
  const failures = [];

  switch (rule.id) {
    case 'T1':
      if (
        typeof signals.bounding_box_width_percentage === 'number' &&
        (signals.bounding_box_width_percentage < 35 ||
          signals.bounding_box_width_percentage > 45)
      ) failures.push(rule.id);
      break;

    case 'T2':
      if (
        typeof signals.distorted_pixel_ratio === 'number' &&
        signals.distorted_pixel_ratio > 0.5
      ) failures.push(rule.id);
      break;

    case 'T3':
      if ((signals.pixel_displacement || 0) > 0 || (signals.rgb_glitch_count || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T4':
      if ((signals.mesh_deformation_delta || 0) > 0 || (signals.boundary_intersection || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T5':
      if ((signals.edge_blur_radius || 0) > 0 || (signals.pixel_bleed_percentage || 0) > 5) {
        failures.push(rule.id);
      }
      break;

    case 'T6':
      if ((signals.high_frequency_pixel_density_delta || 0) < 0 || (signals.edge_halo_detection || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T7':
      if ((signals.z_blue_delta_e || 0) > 0 || (signals.z_blue_color_shift_detected || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T8':
      if ((signals.saliency_peak_zone || '') !== 'product_safe_zone') {
        failures.push(rule.id);
      }
      break;

    case 'T9':
      if ((signals.rgb_chromatic_split_noise || 0) > 0 || (signals.vhs_noise_pattern || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T10':
      if ((signals.line_angle_deviation || 0) > 5 || (signals.grid_snap_variance || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T11':
      if (Math.abs(signals.exposure_value_delta || 0) > 0.3 || (signals.histogram_clipping || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T12':
      if ((signals.geometry_symmetry_ratio || 100) < 98 || (signals.eye_detection_confidence || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'T13':
      if ((signals.line_curvature_degree || 0) > 0 || (signals.ornament_bounding_box || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I1':
      if ((signals.human_eyes_detected || 0) > 0 || (signals.face_mesh_visible || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I2':
      if ((signals.high_gloss_specular || 0) > 0 || (signals.pvc_plastic_read || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I3':
      if ((signals.missing_weave_texture || 0) > 0 || (signals.soft_fabric_folds_on_joints || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I4':
      if ((signals.magenta_neon_spill || 0) > 0 || (signals.chaotic_particle_bloom || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I5':
      if ((signals.toon_shading || 0) > 0 || (signals.chibi_proportions || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I6':
      if ((signals.cyan_magenta_overload || 0) > 0 || (signals.lens_flare_spam || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'I7':
      if ((signals.silhouette_read_time || 0) > 1 || (signals.edge_separation_score || 1) <= 0) {
        failures.push(rule.id);
      }
      break;

    case 'C1':
      if ((signals.recognition_time_seconds || 0) > 1 || (signals.primary_subject_confidence || 1) <= 0) {
        failures.push(rule.id);
      }
      break;

    case 'C2':
      if ((signals.logo_overlap_ratio || 0) > 0 || (signals.branding_zone_distortion_contact || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    case 'C3':
      if ((signals.thumbnail_subject_retention || 1) <= 0 || (signals.thumbnail_saliency_rank || '') !== 'subject') {
        failures.push(rule.id);
      }
      break;

    case 'C4':
      if ((signals.product_color_delta_e || 0) > 0 || (signals.regional_hsv_shift || 0) > 0) {
        failures.push(rule.id);
      }
      break;

    default:
      break;
  }

  return failures.length === 0
    ? { passed: true, rule_id: rule.id }
    : { passed: false, rule_id: rule.id, priority: rule.priority };
}

function runRuleEngine({ specPath, signals }) {
  const spec = loadJson(specPath);
  const results = spec.map(rule => evaluateRule(rule, signals));
  const failed = results.filter(r => !r.passed);
  const priorities = failed.map(r => r.priority);
  const decision = decisionFromPriority(priorities);

  return {
    passed: decision.passed,
    block_level: decision.block_level,
    decision: decision.decision,
    failed_rules: failed.map(f => f.rule_id),
    rule_results: results
  };
}

module.exports = {
  runRuleEngine
};
```
