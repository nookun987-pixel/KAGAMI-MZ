## 0. CORE PRINCIPLE (what makes it "correct")

Mikage = **Vessel** — a porcelain shell containing an ancient consciousness that the Empire purged. Every design choice must read as: **ordered shell outside, living / entropy leaking from inside.** That tension is the master constraint; all detail serves it.

---

## 1. HEAD / FACE

- Canonical face = **faceless porcelain helmet**, exactly **2 horizontal sensor slits**, graphene underlayer exposed at neck / joints. No eyes, nose, mouth.
- Expression is carried entirely by: **slit light (violet pulse)**, head tilt, orbital ring. No face → emotion lives in light + posture. This is where most drawings fail (adding a face breaks it).
- Film layer MAY overlay **Kitsune-mask + violet orbital ring** as a halo for cinematic shots.

**RECONCILE vs LOCKED canon (§2 of entity spec):**
- Locked: the 2 sensor slits ARE the film mask's 2 eye-slits, and they are **SEALED (sealed monocoque, 0.7", no open holes)**; vision routes through a graphene + side-channel BMF sensor beneath the shell. ✅ Compatible — "violet pulse" is read as a **brand/signal light treatment over sealed slits**, not an open optical aperture. Keep slits sealed; violet is emitted signal, not a hole.
- Kitsune mask: locked canon keeps the **Kitsune planar-geometry silhouette** as the mask form itself. Operator direction here treats Kitsune-mask as a possible **film-layer overlay/halo**. → HOW the Kitsune mask integrates (the mask's own geometry vs an added overlay) is an open item — see §7 UNCONFIRMED #3.

## 2. MATERIAL / SURFACE

- Porcelain shell matte→satin.
- **Kintsugi cracks** = where the ancient consciousness shows through (track tag: KINTSUGI). Operator note: described as **gold**, and as "the only warm note permitted."
- Beneath the porcelain: dark woven **graphene**, exposed at slits / joints / neck.

**RECONCILE vs LOCKED canon — DIVERGENCE, `CHUA_XAC_NHAN` (operator decision required):**
- **Kintsugi colour:** operator direction = **gold (vàng)**. LOCKED entity spec §1 Pha 2 = Kintsugi cracks filled with **conductive resin + quantum blood #E60000 (crimson)**. These disagree on colour. NOT resolved here.
- **Kintsugi phase-gating:** operator direction reads kintsugi as a general/always-allowed warm note. LOCKED canon gates cracks to **Phase 2 (Fallen/Exile) and Phase 3**; **Phase 1 (Imperial Clean) = sterile, NO micro-cracks, NO kintsugi.** If the direction is "P1 clean / cracks only P2–P3," it matches canon; if "kintsugi visible in P1," it conflicts. NOT resolved here.
- Porcelain shell hex: operator palette uses porcelain **#f2eeea** (see §4); LOCKED shell = B4C matte white **#FAFAFA**. Minor divergence, flagged.

## 3. SILHOUETTE / BODY

- **High-collar executor coat**, long lines, hard near-zero-radius edges, tall frame that works with negative space.
- Signature prop: **Zenith Blade ~350 kg** — heavy, planted, cold. Held like a heavy object, never swung lightly. (Cross-ref `MIKAGE_ZENITH_BLADE_SPEC_V1.md`; P1 = closed B4C Compact-Idle block, flux-pinned to back.)
- Only intimate object: **Analog Broken Watch** — reserved for the "original identity" beat.

## 4. PALETTE

- Ground: void `#050508` + porcelain `#f2eeea`.
- Signal: violet `#8F00FF` (slit, orbital ring, "consciousness" glow) — **accent only, never a full wash.**
- **Film layer only** may add **Z-Blue / cold cyan** (Empire / Neon Grid side) and **crimson core** (entropy / danger). These two colours are **forbidden in Canvas / UI**.

(See §2 note on porcelain hex divergence vs canon `#FAFAFA`.)

## 5. MOTION / DEMEANOUR (cinematic)

- Slow, heavy, deliberate. **Static > dynamic.** The Vessel is ancient and heavy.
- Comes alive through: head tilt, **slit breathing (violet breathing)**, orbital rotation, light drift of hair / coat.

---

## 6. HARD "DON'T" LIST (to avoid "worse than anime")

- No human face / eyes / skin on the brand mark — **the helmet IS the face.**
- No anime cute / moe. This is cold, monumental, funereal — not adorable.
- No neon clutter, no game HUD, no violet wash.

### Two-layer composition rule (the crux)
- Build the character on the **film / art canon** (Kitsune / coat / blade / kintsugi / Z-Blue) for MV / teaser / character art.
- **Spotify Canvas + UI** use only the **reduced brand version**: faceless helmet + void / porcelain / violet-signal. Same character, two registers — do not let the warm / cinematic treatment leak into Canvas.
- ✅ Matches LOCKED canon §2: brand mark and film entity are ONE identity at two fidelities; "keep layers separate" = don't let one invent the other's canon, NOT that they look different.
