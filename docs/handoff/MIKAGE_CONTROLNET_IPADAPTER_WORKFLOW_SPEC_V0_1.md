## 1. PROBLEM STATEMENT

Four real renders on FAL (V0.1 attempt_004 flux/dev; V0.2 attempt_004 flux/dev; V0.2 attempt_006 flux-pro/v1.1; cross-validated) confirmed three prompt-only failure modes that NEITHER `fal-ai/flux/dev` NOR `fal-ai/flux-pro/v1.1` resolved under explicit positive prompt + explicit negation:

| Fail mode | What the model produced instead | Spec-required |
|---|---|---|
| **POSE_HANDS_BEHIND_BACK** | Hands hanging at sides (canonical "humanoid robot at rest" default) | Both hands clasped strictly at small-of-back; zero hand pixels visible from front |
| **SHIELD_HYBRID_PHASE_1_DORMANT** | Bare forearm; no disc emitter | Single ~15-30 cm disc emitter folded flat on left forearm, Empire sigil etched |
| **MONOWIRE_HOLSTERED** | Hilt absent (V0.2/V0.2 both) or replaced with pistol (V0.1) | Slim ~20-25 cm cylindrical hilt holstered at right hip; no blade, no firearm |

Prompt strength scaling (V0.2 redesign with front-loaded positive cues + 108-term negative) did NOT solve these. Model swap (flux/dev → flux-pro/v1.1) did NOT solve these. **Conclusion:** prompt-only on flux family is the wrong tool. Need structural conditioning.

## 3. LAYER 1 — CONTROLNET MODEL SELECTION

Three ControlNet types are candidates. Recommend running **all three in parallel** for the first Lyre attempt (operator can drop any that don't add value after the first render).

### 3.1 OpenPose ControlNet — POSE LOCK

| Spec | Value |
|---|---|
| Model | `controlnet-openpose-sdxl-1.0` OR `controlnet-canny-sdxl-1.0` if SDXL base; `flux-controlnet-pose` if flux base |
| Purpose | Force the figure into the "parade rest / at-ease military" pose with both hands clasped strictly behind the back |
| Input artifact | OpenPose skeleton JSON keypoints showing: feet shoulder-width; weight even; spine vertical; both upper arms angled back; both forearms crossed at the small-of-back; head level |
| Conditioning weight | Start at 0.7-0.8 (strong); reduce to 0.5-0.6 if armor reads as too thin |
| MAPS TO LYRE LOCKS | LOCK_01 (hands behind back) · LOCK_02 (no visible hands from front) · LOCK_10 partial (pose discipline |
| Source pose | EITHER: (a) photograph a reference person in the pose then run OpenPose detector; (b) hand-build skeleton in software (OpenPose editor extensions exist for ComfyUI / A1111) |

### 3.2 Canny / Depth ControlNet — SILHOUETTE LOCK

| Spec | Value |
|---|---|
| Model | `controlnet-canny-sdxl-1.0` or `controlnet-depth-sdxl-1.0` |
| Purpose | Force the body silhouette to read as flat rectangular industrial column instead of female-android curvy default |
| Input artifact | Hand-drawn outline showing: rectangular chest plate; vertical waist line; vertical hip line; no breast contour; no thigh emphasis. Canny edge map from a Boris Vallejo / Roger Dean industrial slab armor reference works |
| Conditioning weight | 0.5-0.7 (medium — let the model add surface detail inside the silhouette) |
| MAPS TO LYRE LOCKS | LOCK_03 (flat rectangular column torso) |
| Source silhouette | Operator hand-draws or sources public-domain industrial slab armor reference (NOT a real IP — must clear LICENSING_CLEAN check) |

### 3.3 (Optional) Depth ControlNet — BACKDROP LOCK

| Spec | Value |
|---|---|
| Model | `controlnet-depth-sdxl-1.0` |
| Purpose | Force the backdrop to read as Imperial Spire monumental scale instead of flux-pro's studio gray default |
| Input artifact | Depth map of an Empire monolith chamber (tall ghost-white plates, vertical light pillar, polished black floor) |
| Conditioning weight | 0.4-0.5 (light — backdrop should still be flux-rendered, just spatially primed) |
| MAPS TO LYRE LOCKS | LOCK_06 (Empire monolith backdrop) · LOCK_11 (no studio gray) |
| Source depth | Render a quick blockout in Blender / SketchUp of the Imperial Spire interior at the correct camera angle, export depth pass |

## 7. NEW VERIFICATION CRITERIA UNDER CONTROLNET

The 11 Lyre locks transfer 1:1 to the local-render verification checklist, with three augmentations specific to the conditioning approach:

| New check | Description | Pass criterion |
|---|---|---|
| **C1_POSE_CONTROLNET_RESPECTED** | Rendered pose matches the OpenPose skeleton input | Compare rendered figure's hand position to skeleton hand keypoints; diff < 10% of body height |
| **C2_SILHOUETTE_CONTROLNET_RESPECTED** | Rendered silhouette stays inside the Canny / depth bounds | Edge map overlay: rendered outline within 10 px of conditioning outline |
| **C3_IP_ADAPTER_OBJECTS_PRESENT** | Disc + hilt are present at the conditioned regions with the conditioned identity | Visual scan: disc clearly on left forearm with sigil; hilt clearly on right hip |

These are ADDED to (not replacing) the existing 11 Lyre locks. The full local-render check sheet = 11 Lyre locks + 3 ControlNet/IP-Adapter integrity checks = 14 checks.
