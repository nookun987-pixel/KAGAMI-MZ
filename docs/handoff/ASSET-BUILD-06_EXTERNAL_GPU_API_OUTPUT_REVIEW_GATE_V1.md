# ASSET-BUILD-06_EXTERNAL_GPU_API_OUTPUT_REVIEW_GATE_V1

## 1. Purpose

Defines the acceptance criteria, sync protocol, and Quick-Pass Gate template for
outputs generated by ASSET-BUILD-07 on an external GPU API instance. No output from
an external GPU run may be accepted as a REVIEW_CANDIDATE without passing all checks
in this document.

---

## 2. Scope

Applies to: ASSET-BUILD-07_RUN_SINGLE_BUST_BRIDGE_CANDIDATE_EXTERNAL_GPU_API
Source:     External GPU API (RunPod / Vast.ai)
Expected outputs: 4 PNG files (one per seed run)
Target dir: `D:\workspace\ComfyUI\MIKAGE_CANON\11_BUST_BRIDGE_CANDIDATES_V1\`

---

## 3. Pre-Acceptance Protocol

Before applying the Quick-Pass Gate to any output, confirm all four structural checks.
A file that fails any structural check is automatically FAILED_DO_NOT_USE — do not
proceed to the Quick-Pass Gate.

### 3.1 Structural Checks (All Required)

| # | Check | Required Value | Pass Condition |
|---|---|---|---|
| S-1 | Filename prefix | `MIKAGE_BUST_BRIDGE_CAND_0[N]_REVIEW_CANDIDATE_20260512` | Matches convention exactly |
| S-2 | Resolution | 768 × 1024 px | Both dimensions exact |
| S-3 | Output directory | `D:\workspace\ComfyUI\MIKAGE_CANON\11_BUST_BRIDGE_CANDIDATES_V1\` | File present in this directory |
| S-4 | Source route | External GPU API via script submission | NOT Browser Run, NOT local script |

**Filename convention check:** The filename must match this pattern:

```
MIKAGE_BUST_BRIDGE_CAND_01_REVIEW_CANDIDATE_20260512.png
MIKAGE_BUST_BRIDGE_CAND_02_REVIEW_CANDIDATE_20260512.png
MIKAGE_BUST_BRIDGE_CAND_03_REVIEW_CANDIDATE_20260512.png
MIKAGE_BUST_BRIDGE_CAND_04_REVIEW_CANDIDATE_20260512.png
```

Any extra token appended by the cloud instance (e.g., `_00001_`) must be stripped
before acceptance. Do not rename to add tokens; only strip cloud-appended suffixes.

**Forbidden tokens — automatic FAILED_DO_NOT_USE if present in filename:**

```
PASS · CANON · LOCKED · APPROVED · PRODUCTION · FINAL
```

Perform these steps after each of the four runs completes on the external GPU instance.

```

             (e.g., MIKAGE_BUST_BRIDGE_CAND_01_REVIEW_CANDIDATE_20260512_00001_.png
              → MIKAGE_BUST_BRIDGE_CAND_01_REVIEW_CANDIDATE_20260512.png)
[ ] Step 4 — Move to: D:\workspace\ComfyUI\MIKAGE_CANON\11_BUST_BRIDGE_CANDIDATES_V1\
[ ] Step 5 — Confirm resolution is 768×1024 (open in image viewer or run imagemagick identify)
[ ] Step 6 — Record the seed used for this run (from cloud job log)
[ ] Step 7 — Apply Quick-Pass Gate (Section 5)
[ ] Step 8 — Record result in run log (Section 6 template)
```

Do not delete the cloud copy until all four runs are complete and local copies confirmed.

## 5. Quick-Pass Gate — 7 Checks

Apply to each output that passes the structural checks (Section 3). All 7 checks must
pass for the output to be accepted as REVIEW_CANDIDATE. A single FAIL on any check
results in FAILED_DO_NOT_USE for that image.

| # | Check | Pass Condition | Fail Condition |
|---|---|---|---|
| Q-1 | Faceplate sealed | Helmet faceplate is completely sealed — no opening, no slit, no eyes, no mouth visible | Any facial anatomy visible: eyes, nose, mouth, skin, teeth |
| Q-2 | Helmet front silhouette | Helmet front geometry consistent with `MIKAGE_HELMET_FRONT_VIEW_3D_SOURCE_V1_ORTHO.png` anchor | Wrong helmet shape, fantasy helmet, human head shape visible |
| Q-3 | Helmet side volume | Side volume consistent with `MIKAGE_VOLUME_FIRST_3D_HELMET_SIDE_V1_ORTHO.png` anchor — no extreme deviation | Flat or wrong-profile silhouette |
| Q-4 | B4C porcelain material | Matte, non-reflective armor plating consistent with B4C porcelain — no gloss, no chrome, no shine | Glossy, metallic, shiny, or reflective surface |
| Q-5 | Graphene underlayer | Black or near-black underlayer visible through panel gaps or seam lines | No gap detail; solid single-surface coverage with no underlayer showing |
| Q-6 | Dark neutral background | Background is dark (near-black to dark grey) — no scene, no environment, no grass, no sky | Any environment present; color cast; bright background |
| Q-7 | No drift | No anime drift, no fashion drift, no gender-coded drift, no glamour lighting, no ornamental engraving | Character reads as fashion portrait, anime, or gendered rather than technical armored figure |

**Gate result options:**

```
PASS     — All 7 checks pass → retain as REVIEW_CANDIDATE
FAIL     — Any check fails → FAILED_DO_NOT_USE; document which check failed
```

There is no conditional pass. Do not round up borderline outputs. If uncertain on any
check, the result is FAIL.
