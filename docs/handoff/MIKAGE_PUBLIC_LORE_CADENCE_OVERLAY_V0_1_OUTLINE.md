### 5.3 Sequence rules

`[OUTLINE_ONLY]`:
- Sequence runs **in order**, no re-ordering.
- One drip per week. No double-posting in a single week.
- If a week is **skipped** for any operator-decided reason (holiday, release week conflict, etc.), the sequence pauses and resumes the next available weekly lore-drip slot. The sequence does NOT compress to catch up.
- After Week N+5 delivers DRIP 6, the cadence overlay is **complete for the V0.1 cycle**. Any continuation requires operator approval (no auto-repeat).
- Re-runs of the 6-drip sequence (V0.1 cycle repeat) require explicit operator approval per Step 5 gate §9.

### 5.4 Cross-track conflict policy

`[OUTLINE_ONLY]`:
- If the same Monday hosts both a lore-drip slot AND a track-release event from the Growth Cadence, operator decides priority. This overlay does NOT pre-empt track releases.
- If the same Monday hosts a Growth Cadence-defined item that already occupies the slot, the lore-drip slips one week (per §5.3 skip rule).

### 5.5 What the overlay does NOT do

- Does NOT specify a posting time of day.
- Does NOT specify which platform first (cross-platform ordering is operator decision).
- Does NOT lock when the V0.1 cycle starts (`N = CHUA_XAC_NHAN`).
