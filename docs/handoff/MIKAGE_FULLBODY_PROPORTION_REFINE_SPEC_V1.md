## 3. PROPORTION DELTA — PROPOSAL (CHUA_XAC_NHAN until operator confirms)

The baseline reads stocky/compressed. Proposed direction = taller, leaner, more grounded-heroic, keeping armored
mass in the shoulders/chest but removing the squat read. **All numbers are proposals for operator confirmation.**

| Attribute | Baseline read (stocky) | PROPOSED target | Note |
|---|---|---|---|
| Total height in heads | ~6 – 6.5 heads | **~7.5 heads** | grounded, not fashion-9-head |
| Leg : total height | short | **legs ≈ 0.50 of total** | lengthen lower limb |
| Torso taper | blocky / barrel | **mild shoulder→waist taper** | keep armor mass up top, trim midsection bulk |
| Shoulder width | wide (good for armor) | **keep broad, slightly narrower** | retain authority silhouette |
| Hip width | wide | **reduce toward shoulder-line balance** | no female flare, no exaggerated taper |
| Forearm / hand scale | chunky | **slightly slimmer, longer reach** | avoid mitten/club hands |
| Neck / head seat | compressed into shoulders | **raise head seat slightly** | removes "no-neck" stocky read |

Hard guardrails on the delta: do NOT introduce thigh-gap emphasis, waist pinch, chest contour, runway pose, or any
gendered/idol read while slimming. "Leaner" = engineering-lean, not glamour-lean.
