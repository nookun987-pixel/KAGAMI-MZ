# ZENITH BLADE — REVEAL STORYBOARD / DIRECTION SPEC

> **Status: DIRECTION SPEC — UNCONFIRMED. Held, not scheduled.** Not production-ready.
> No asset is locked here. This is shot/colour direction for the **film / MV / world-art

## 1. Why it is held (placement in the Launch Arc)

The public arc so far is deliberately subtractive:

1. **World key art** — the signal, the void, "a world is forming in the dark." (absence)
2. **Character key art** — Mikage, the sealed one (鏡). A presence given to the signal:
   faceless porcelain helmet, two sensor slits as the lone violet locus. (form)
3. **→ Zenith Blade** — the weapon / conflict. (force) ← **this doc, held for later**

The Blade is the first true escalation from *signal* to *force*. Revealing it before the
character is established spends the mystery early and breaks the "silence instead of
spectacle" thesis. It also lives in a **different visual layer** with a different palette,
so it must not appear on a brand-signal poster. Trigger only once Mikage is canon and the
audience is asking *what is it for*.

## 2. Layer & palette lock (cine color contract — NOT the brand layer)

This reveal uses the **CINE / FILM / WORLD-ART** palette, never the brand UI palette.

| Role | Colour | Hex | Rule |
|---|---|---|---|
| Structural black (70%) | Sumi-iro | `#252321` | primary volume; never pure `#000` |
| Highlight (sparse) | Angora White (Gofun) | `#F6F5F6` | shell-warm white; never pure `#FFF` |
| Core / seam crimson | Bengala / Enji | `#8E050F` / `#9D2933` | seams, cores, sacred objects ONLY |
| Max-chroma point (rare) | British Red | `#D11033` | single sacred point at peak only |
| Cold metal | Z-Blue (Ao-zumi) | `#4B5866` | the only cold blue; non-emissive |
| Kintsugi seam | Aged Urushi-gold | `#C39A52` | matte, on seams only, raking-light glow |
| **Violet — sole emissive exception** | Electric Violet | `#8F00FF` | **only** the two slit-halos OR the P3 execution core |

Hard rules: 70/30 shadow; max saturation ≤65% HSL except crimson core / gold-seam centre;
no neon RGB; no spectral/neon blue; chroma decays with distance from active seams/cores.

## 3. The violet bridge (continuity, used once)

Violet is the thread between brand and film. In this reveal it appears in exactly two
sanctioned places and nowhere else:

- **(a) Slit halo** — the faint violet from Mikage's two sensor slits (carried from the
  character key art).
- **(b) P3 Overdrive / Execution core** — the Blade's conflict core *at peak state only*.

The dramatic beat = the moment (a) and (b) **sync**: the slit-halo and the blade-core pulse
on the same frequency. That single synced pulse is the whole reveal. Everything else stays
subtractive mineral (Sumi-iro + crimson seams + kintsugi).

## 4. Shot list (loose cinematic timing — anti-karaoke, slow)

Proposed ~20–25s teaser. Slow fades (0.6–1.4s), draw-on, breath between beats.

1. **Black. A seam.** Sumi-iro full frame. One **kintsugi-gold seam** draws on under raking
   light — the only thing visible. (hold, ~3s)
2. **The object in shadow.** The Blade lies horizontal, 90% in shadow; we read its mass
   (350 kg — weighted, grounded, not floaty) by silhouette and one crimson seam, not by a
   hero light. (~3s)
3. **Mikage enters frame edge.** Only the porcelain shell + two slits, off-centre. Slit-halo
   faint violet. No face turn, no drama. (~3s)
4. **Contact.** Hand/shell nears the hilt; the **crimson core (Enji)** wakes — saturation
   climbs along the seams from the contact point outward (chroma decay reversed). (~3s)
5. **The sync.** Slit-halo and P3 core pulse **once, together**, on the same beat — the only
   violet in the film. Cut on the pulse. (~1s, the hit)
6. **Mass moves.** A single slow lift — weight sells it; British Red `#D11033` flickers at
   the core's max-chroma peak for a few frames, then decays. (~3s)
7. **End card.** Back to near-black. Wordmark **MIKAGE ZENITH** (Cinzel) + one mono line.
   No track name / no date unless a specific transmission is being attached. (~3s)

## 5. Open decisions (operator — do not guess)

- **Mask in the film layer.** Brand canon = porcelain helmet. The older film canon referenced
  a **kitsune mask**. Which reads in this reveal is **UNCONFIRMED** — pick one and lock it
  before any render. The two layers must not silently contradict.
- **Tie to a transmission?** Reveal can be world-level (no track) or attached to a specific
  release. Operator decides; CTA grammar then follows (`Pre-save` / `Listen now`).
- **Audio bed.** Existing cinematic instrumental (e.g. the wide-LRA saved lane) vs. a track
  cut — operator's call. Anti-karaoke: no synced lyric text on the visual.
- **Format.** Same matrix as the key arts (4x5 / 1x1 / 9x16 / 16x9) if it ships as stills, or
  a motion teaser.
