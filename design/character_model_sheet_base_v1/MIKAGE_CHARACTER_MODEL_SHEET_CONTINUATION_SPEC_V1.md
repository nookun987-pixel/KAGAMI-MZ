## 2. MODEL-SHEET SPEC (per part — targets for the next sheet, not art)
Each entry = what the next sheet must show, sourced from the V2 4-view + the studies. All
values are DRAFT and inherited from source; none are newly invented here.

**A. Proportion / layout** — 7.1 heads total. Four columns, equal scale, shared horizontal
landmark guides. Heavy/monolith calm mass; female-coded **non-sexual** column (waist defined
by silhouette only). Per-view captions: FRONT(slit halo·hair·skirt) / SIDE(hair down back·
skirt depth) / BACK(Ensō·hair covers back·no slits) / 3-4(mask+hair+coat+skirt+violet check).

**B. Helmet / mask** — Faceless sealed Kitsune planar mask (faceted faceplate + muzzle wedge,
planar cheeks). Exactly 2 sealed flush slits on FRONT + 3/4 only; NONE on BACK. No eyes /
mouth / nose / skin. Matte. Mask nests into gorget collar (minimal neck). Source: V1.3 mask + V2.

**C. Hair** — Long heavy black; wider at head+shoulders; straight vertical fall; tail past hip.
Dominant silhouette in BACK; shown falling down back in SIDE/3-4. Source: V2 rulings 1.

**D. Coat (executor)** — High standing collar framing mask in a V; closed center seam
(front/3-4), single center-back seam (back); straight sleeves to wrist (hands exposed);
heavy single knee hem; hangs straight, not a cape. Source: Costume Coat V1 / V1.1.

**E. Skirt panels** — Layered vertical panels below the coat hem; outer panels toward the
ankle (sacred long-line flow); panel-separation hairlines readable in all 4 views, visible
below hair mass in back. Source: V2 ruling 4.

**F. Body / silhouette** — Segmented sealed porcelain shell; "not human mannequin, not robot
armor, not mascot blob." Defined waist + long vertical column; no anatomy emphasis.

**G. Hands** — Sealed-shell mitten / segmented ceramic glove: no fingers, no nails, thumb nub.
Source: V1.4 hands+feet (placeholder segmentation — see §4).

**H. Feet** — Heavy sealed boots, toe + sole edge, grounded. Source: V1.4 (placeholder sole).

**I. Surface / material** — Matte unglazed B4C porcelain (fine micro-grain); graphene charcoal
underlayer at every joint (neck/shoulder/elbow/wrist/hip/knee/ankle); flush engraved slit
grooves; recessed gorget + minimal panel seams. **MATTE LOCK** — no gloss/chrome/specular/
subsurface. Source: Surface Material Study V1.

**J. Palette (white + black + violet only)** — Porcelain albedo `#FAFAFA`; garment/hair black
`#16161c` (deep recesses `#0d0d12`/`#09090d`/`#08080c`); graphene `#24242b`; violet `#8F00FF`
signal only. Material-study greys (`#8d8a83`/`#c4c0b8`/`#ece9e3`, slit groove `#3a3a42`, void
`#050508`) are shading values, not added palette colors.

**K. Violet signal** — SIGNAL ONLY, never a plate fill: (a) ultra-thin halo on the 2 sealed
slits (front + 3/4; one faint edge in side), (b) exactly ONE Ensō ring at the upper back / nape.
No broad violet, no ambient tint. Ensō carries forward because it already exists in the V2 source.
