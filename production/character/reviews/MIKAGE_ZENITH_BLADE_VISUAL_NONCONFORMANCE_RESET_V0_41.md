## Nonconformance

The accepted V0.29 lineage passed material, phase, registration, collision,
repeatability and packaging gates, but its four parallel shell elements read
as an opening box rather than a unified Zenith Blade.

It failed the newly promoted structural target:

- no decisive long tapered weapon silhouette;
- no pointed directional tip;
- central spine did not dominate the load path visually;
- separated shell elements became the primary outer read;
- P2/P3 lost continuous blade identity.
