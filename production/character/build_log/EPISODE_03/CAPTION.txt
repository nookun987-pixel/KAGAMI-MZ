BUILD LOG 03 — The design code.

A character you can recognize in one glance needs rules that don't bend.

Swipe → the code behind Mikage: one faceless mark (exactly two slits), three
colors (void, porcelain, violet-as-signal), monolithic forms, the lines we
never cross, and the voice that carries it all.

Lore can grow. Scenes can change. The code doesn't.
From the void, it learned a shape — this is what keeps it.

— MIKAGE ZENITH
