## 0. DOCTRINE (one line)

**Melody is the carrier. Lyric density rides the genre lane.** A listener locks onto
sound before sense — so what they *can sing back* is engineered first, and cleverness is
spent only where the lane pays for it (rap verses). **[CANON]**

---

## 1. THE TWO LANES — the central rule

Every track is assigned ONE primary lane before writing. The lane sets density,
vowel discipline, and where wordplay is allowed. **[CANON]**

```
MELODY LANE  (default — Pop / Alt-Indie / Electronic / non-rap)
  - Melody leads. The topline is written to be SINGABLE first, meaningful second.
  - Open vowels (/a/ /o/ /e/) land on held / peak notes — they ring; closed sounds choke.
  - Hook is REPEATABLE and LOW-DENSITY — survives one listen, recalled cold.
  - Wordplay restrained. Clever-but-unsingable lines are cut, not admired.

RAP LANE  (Hip-Hop / Rap tracks — e.g. KINTSUGI, 墨雨 INK RAIN)
  - Density unrestricted in VERSES. Internal rhyme, multis, wordplay all welcome here.
  - The HOOK still obeys the Melody Lane: singable, low-density, open-vowel peak.
  - Density is a verse privilege, never a hook excuse.
```

**Hard rule:** dense / clever wordplay belongs in **rap verses only**. If a non-rap track
needs cleverness, it goes nowhere — rewrite for singability. **[CANON]**

## 2. DENSITY BY GENRE (syllable load — rough guide)

Per-bar syllable feel, not a literal counter. **[SCAFFOLDING]**

| Lane / section | Target feel | Syllables/bar (approx) |
|---|---|---|
| Melody — hook peak | sparse, held, open vowel | 2–6 |
| Melody — verse | conversational, breathing | 6–10 |
| Melody — pre-chorus | lift, slight crowd | 8–11 |
| Rap — verse | dense, no ceiling | 12+ |
| Rap — hook | **same as Melody hook** | 2–6 |

Genre tags currently source-confirmed: GLASS SKIN (EN) = Pop / Alt-Indie → Melody Lane ·
ALIGN = Electronic / Industrial-Noise → Melody Lane (texture-forward) ·
KINTSUGI = Hip-Hop/Rap / Alternative → Rap Lane · SHARD-513 = Pop / Electronic → Melody Lane.
All other catalog genres `UNCONFIRMED` — assign lane per track before writing, do not infer.

## 3. SECTION GRAMMAR (song form scaffolding)

Single-format default (~2.5–3.5 min). Tighten freely; this is a skeleton, not a cage. **[SCAFFOLDING]**

```
MELODY LANE default:
  INTRO (≤8 bars) → V1 → [PRE] → HOOK → V2 → HOOK → BRIDGE → HOOK(final lift) → OUTRO(short)

RAP LANE default (hook-first is common):
  INTRO → HOOK → V1 → HOOK → V2 → HOOK → [SWITCH/BRIDGE] → HOOK → OUTRO(short)
```

Rules:
- **One hook position per song.** The hook lands at the same structural slot every time —
  never drifts. **[SCAFFOLDING]**
- **Title-in-hook** by default: the release title usually surfaces inside the hook line,
  unless a deliberate withhold. **[SCAFFOLDING]**
- **Bridge = one idea.** A single turn (lift, drop, or reveal) — not a second verse. **[SCAFFOLDING]**
- Intro/outro stay short — the catalog is singles, not album cuts. **[SCAFFOLDING]**

---

## 4. HOOK / TOPLINE RULES

The hook is the asset. Build it to outlast the track. **[CANON + SCAFFOLDING]**

- **One central image or word per hook.** No competing payloads. **[CANON]**
- **Recallable cold** — if it can't be hummed after one pass, it's not a hook yet. **[CANON]**
- **Open vowel on the peak / held note** — the note that rings is /a/ /o/ /e/, not a closed
  cluster. Engineer the vowel to the melody, then fit meaning. **[CANON]**
- **Repetition is structure, not laziness** — the hook may repeat verbatim; the lift comes
  from arrangement, not from rewriting the line. **[SCAFFOLDING]**

## 5. LANGUAGE HANDLING (EN / JA / ZH / KO / VI)

For multilingual versions (e.g. GLASS SKIN EN → ガラスの肌 JA), structure is parallel,
wording is not. **[CANON — from established practice]**

- **Parallel section structure:** the JA/ZH/KO/VI version keeps the SAME song form, and the
  hook lands at the SAME structural position as the source. **[CANON]**
- **Adapt, don't translate the hook.** The hook is rebuilt for the target language's
  phonology so it stays singable — open-vowel-on-peak applies **per language**, not by
  literal carry-over. A literal translation that kills the vowel is wrong. **[CANON]**
- **Line-break for the recording, not the page.** When laying out lyrics, break by sung
  phrase / structural parallel to the source, not by sentence grammar. **[CANON]**

---

## 6. LYRIC HYGIENE (public sheet + sync)

Two separate artifacts: the **generation/direction sheet** (private) and the **published
lyric** (public / Musixmatch). They are NOT the same file. **[CANON]**

- **Strip all production cruft from public lyrics.** No stage directions, voice tags, or
  section-title headers embedded in the lyric body — e.g. `(Low voice):`, `(Whisper):`,
  `[Glitch]`, `THE ARCHITECT'S RECOVERY`. Keep the sung words only. **[CANON]**
- **Recording-truth rule:** synced lyrics must match the **actual recording**, not the
  pre-generation sheet. Every repeated section heard in the audio must be present in the
  submitted lyric. If Suno repeated a hook 3×, the sheet shows it 3×. **[CANON]**
- **No emoji anywhere in lyrics or titles.** **[CANON]**

---

## 7. VOICE / TITLE / CTA (reference — owned by brand layer)

These live in the brand/voice canon; restated here so a writer doesn't drift. **[CANON]**

- Outward voice: calm, mysterious, minimal. Releases framed as "transmissions."
- Title styling: native script + romanization where used in catalog (e.g. `墨雨 (INK RAIN)`).
- CTA grammar is binary and status-locked: `Pre-save` (PRE-SAVE) **or** `Listen now` (LIVE) —
  never mixed, never neutral.

---

## 8. ANTI-KARAOKE (short-form — reference)

Short-form visual rule, restated so lyric timing isn't mistaken for vocal-sync. **[CANON]**

- No vocal-synced text in shorts. Use loose cinematic timing (~6–7s/unit), deliberately
  **offset** from the vocal. The lyric is a mood layer in shorts, not a karaoke track.

## 9. PRE-FLIGHT CHECK (writer self-verifies before calling a topline done)

Report each PASS / FAIL / N/A. Any FAIL → fix, do not ship.

- [ ] Lane assigned (Melody / Rap) BEFORE writing?
- [ ] Density matches the lane — verses dense only if Rap Lane?
- [ ] Hook is low-density, repeatable, recallable after one listen?
- [ ] Open vowel (/a/ /o/ /e/) on the hook peak / held note?
- [ ] Wordplay confined to rap verses (none smuggled into a melody topline)?
- [ ] One hook position, one central image per hook?
- [ ] Multilingual version: parallel structure + hook adapted (not literal-translated)?
- [ ] Public lyric stripped of stage directions / tags / section titles?
- [ ] Synced lyric matches the REAL recording (all repeats present)?
- [ ] No emoji in lyric or title?
- [ ] Anything unknown flagged `UNCONFIRMED`; nothing self-certified PASS without source?
