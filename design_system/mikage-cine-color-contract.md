## PHYSICS / BUDGET (hard numbers)

```
SHADOW VOLUME   >= 70% of frame = Black + dark-Earth family.
SACRED FAMILY   <= 30% = whites / crimson / gold.
MAX SATURATION  <= 65% HSL — EXCEPT crimson core or kintsugi-gold center.
NOISE FLOOR     >= 4% grain/texture EVERYWHERE — no flat uniform area.
CHROMA DECAY    saturation drops with distance from active seams/cores.
AGING           saturation inversely proportional to age (weathered = quiet).
```

## ⚡ VIOLET — THE SOLE SANCTIONED EMISSIVE EXCEPTION (LOCKED 2026-06-04)

```
#8F00FF  Electric Violet (brand signal) — the ONLY emissive break allowed in cine.
  ALLOWED, narrowly, as "cold plasma surge":
    (a) Slit Halo — faint emissive glow from the mask's TWO sensor slits, or
    (b) P3 Overdrive / Execution core — the driver/weapon conflict core at peak state.
  FORBIDDEN everywhere else: no decorative violet, no fills, no washes, no ambient tint,
  no violet on any surface that is not (a) the two slits or (b) a P3 core.
  Rationale: preserves visual continuity with the brand signal across Landauer phases
  without breaking the subtractive-mineral world elsewhere.
```

## FORBIDDEN

```
- Emissive / neon RGB (e.g. #00FF00) — all light reflected, EXCEPT the §VIOLET exception.
- Spectral blue #0000FF / high-frequency or neon blue (Z-Blue #4B5866 is the only cold blue).
- Synthetic magenta #FF00FF range.
- Pure #FFFFFF / pure #000000 (no R0G0B0 clusters). Whites carry shell-warmth; blacks carry ink-depth.
- Flat uniform color / "plastic RGB cleanliness" — always soot / ash / mineral grain.
- High specular on plaster / paper / sumi (only Urushi lacquer + metal may gloss).
- Oversaturated game-art clash palettes.
- Any color without a material reason ("red because it is an iron seam" — yes; "red for vibe" — no).
```

## TEXTURE & LIGHT

```
- Keshiki on every surface: pinholes, crawling, carbon-trapping, soot, ash.
- Highlights = diffuse anisotropic glow (no single hard point); Shino = "beading."
- Gradients = bokashi: dense for ~80% then quick bleed (ink on wet paper).
- Shadows = "wet/heavy," temperature-shifted (Ao-zumi blue / Cha-boku red), never monochrome.
```
