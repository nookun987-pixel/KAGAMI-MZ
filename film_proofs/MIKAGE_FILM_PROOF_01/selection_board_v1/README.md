# MIKAGE_FILM_PROOF_01 Selection Board V1

Purpose: provide a human-facing board for selecting or rejecting the three required plate roles before any Mikage film proof planning continues.

This board is documentation and candidate organization only. It does not approve canon, create an asset lock, create a FILM-02 shotlist, render, generate image/video, run ComfyUI, use Blender, or create public output.

## Required Plate Roles

- `ENVIRONMENT_WORLD_PLATE`
- `CHARACTER_PRESENCE_BEYOND_MASK_PLATE`
- `EVENT_SYSTEM_PLATE`

## Current Decision State

- IMMEDIATE_FILM_02_ALLOWED: NO
- CURRENT_FILM_READY_ASSET_SET: NO
- CURRENT_MASK_KEY_VISUAL_BLADE_SET: REFERENCE_ONLY

## Files

- `HUMAN_SELECTION_BOARD.md`: human approval/rejection surface.
- `CANDIDATE_PLATE_INDEX.md`: candidate paths and evidence notes.
- `DECISION_TEMPLATE.md`: copyable decision form for the next human task.

## Selection Rule

A mask close-up, key visual, or blade still can be useful reference material, but those files do not by themselves create a film-ready asset set.
