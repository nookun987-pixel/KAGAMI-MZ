# 2. Design Philosophy

LORA uses **System Presence** as the dominant design language.

LORA does not have a silhouette. LORA has a field.

The design must create presence through:

- architectural scale geometry
- sterile white void as the dominant spatial field
- cold cyan as LORA server light / synchronization signal / Orbital Logic interface
- clean digital gold as Golden Patch event accent only, not dominant
- void black as secondary boundary/depth accent only
- absolute bilateral symmetry
- mechanical Enso ring logic
- golden patch / clean code event visualization

LORA must feel like the operating system of the world, not a soldier, not a figure.


Gold hex value: CHUA_XAC_NHAN — not canon-locked. Do not use warm fantasy gold. Use cold, precise, digital gold logic.
Cold Cyan hex: #00FFFF — same wavelength as used in LORA synchronization and server-field contexts.

## Color Hierarchy

1. White void is LORA's dominant spatial field — the primary environment.
2. Cold cyan defines LORA's active server light and synchronization signal.
3. Clean digital gold is the Golden Patch event accent — appears as a precise intervention, not a wash.
4. Void black is secondary — boundary lines and depth only.

- noisy neon (Slums palette — rejected by LORA's system field)
- cyberpunk clutter palette
