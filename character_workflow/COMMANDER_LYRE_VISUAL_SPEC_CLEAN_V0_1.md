# 2. Design Philosophy

Lyre uses **Porcelain Minimalism** as the dominant design language.

The design must create pressure through:

- extreme cleanliness
- sterile perfection
- visual emptiness
- high-gloss porcelain surfaces
- authoritarian symmetry
- cold cyan control light

Lyre must feel like an alien imperial object entering the Slums, not a normal human soldier.

Lyre wears a flawless imperial porcelain mask/helmet.

Lyre's mask may include ultra-thin technical grooves:

- cold cyan emission
- static glow only
- no blinking
- no unstable flicker

The cyan light represents controlled logic and imperial command, not emotional energy.

# 4. Armor Architecture

## Layer Structure

```text
OUTER_LAYER = Flawless white porcelain / Boron Carbide B4C armor plates
UNDER_LAYER = Dark nickel-gray high-density carbon-fiber under-suit
JOINT_SYSTEM = Precise mechanical / hydraulic joint logic
ACCENT_ENERGY = Internal red #E60000, hidden and compressed
SURFACE_STATE = Pristine / sterile / execution-ready
```

## Outer Armor

The exterior armor uses white porcelain / Boron Carbide ceramic plates.

Key zones:

- chest
- shoulders
- forearms
- major command-silhouette surfaces

Surface rules:

- pristine
- sterile
- no scratches
- no rust
- no Slums dirt
- no battle grime unless explicitly story-approved later
- laser-cut edges
- ceremonial but dangerous

## Under-Suit

The under-suit is dark nickel-gray carbon fiber.

It appears only at:

- mechanical joints
- moving seams
- under armor gaps
- hydraulic support areas

It should never expose human skin.

## Internal Red Accent

Red is not Lyre's main energy identity.

Use internal red only as hidden compressed violence:

- spine vents
- heat seams
- deep joint gaps
- internal energy core glimpses

```text
RED_USAGE = contained / compressed / hidden violence
CYAN_USAGE = surface command / control / imperial logic
```

# 6. Signature Weapon System

## Canon Weapon Direction

Lyre does **not** use Mikage's brutal heavy weapon language.

```text
MIKAGE_WEAPON_LANGUAGE = massive Zenith Blade / brute force / industrial rupture
LYRE_WEAPON_LANGUAGE = Molecular Monowire / Force-field Lyre / remote precision cutting
```

## Weapon Form

Inactive state:

- slim elongated white ceramic device
- worn at hip or back
- minimal and ceremonial
- not a sword
- not a shield slab

Active state:

- ultra-thin cyan energy strings
- molecular monowire / force-field logic
- precise, distant, surgical cutting potential

## Optical Effect

Active Lyre strings create visual distortion:

- Landauer heat distortion
- refraction warping
- faint air shimmer
- compressed energy density

The weapon should feel quiet, precise, and terrifying.
