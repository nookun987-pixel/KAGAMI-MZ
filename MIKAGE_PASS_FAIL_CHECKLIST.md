# MIKAGE ZENITH — PASS/FAIL CHECKLIST

**Version:** 2.0

**Use:** Quality control for all visual outputs

## A. PASS IF

### Silhouette
✓ Clean geometric blocks  
✓ Slender, elegant form  
✓ Delicate curves, non-sexualized  
✓ No external clutter (cables, tubes, loose parts)  
✓ Readable at thumbnail scale

### Mask Signature
✓ Faceless white helmet, smooth aerodynamic  
✓ Void black optical sensors (no pupils, no glow)  
✓ Long straight black hair, natural flow  
✓ Emotionless, static expression  
✓ Subtle fox-like silhouette (not traditional anime mask)

### Blade Readability
✓ Massive, oversized, industrial  
✓ Absolutely straight (zero curvature)  
✓ Dark rusty titanium plates  
✓ Glowing crimson core visible  
✓ Thick rectangular block geometry

### Material Correctness
✓ Porcelain white (#FAFAFA) armor shell, glossy or smooth matte  
✓ Matte black (#0A0A0A) graphene hex-grid undersuit visible at joints  
✓ Fine gold kintsugi seams on cracks  
✓ Deep crimson (#E60000) energy/blood leaking from damage  
✓ Dark titanium satin joints

### Lighting Hierarchy
✓ Chiaroscuro 4:1 contrast ratio  
✓ Single motivated key light (45° soft)  
✓ Sharp rim light separating subject from background  
✓ Deep graphite black shadows with volume  
✓ Highlights preserve porcelain texture detail

### Environment Discipline
✓ Physical consequences visible (steam from heat, cracked concrete, thermal mirage)  
✓ Atmospheric depth (mist, rain, acid haze)  
✓ Background creates contrast (cyan/violet environmental light on white porcelain)  
✓ Brutalist architecture or industrial slum setting  
✓ Heavy negative space (Ma principle)

### Emotional Tone
✓ Silent, controlled, disciplined  
✓ Tragic, isolated atmosphere  
✓ Luxury through restraint  
✓ Authoritative presence

### Identity Consistency
✓ Only 3 colors on character body: White, Black, Red  
✓ Kintsugi gold ultra-thin seams only  
✓ No cyan/green/orange/yellow on armor  
✓ Environmental colors reflect onto porcelain, not painted on

## B. FAIL IF

### Anatomical Violations
✗ Exposed human face visible  
✗ Human eyes, pupils, or iris showing  
✗ Lips, mouth, or facial features  
✗ Animal ears (fox ears, cat ears, etc.)  
✗ Organic skin texture anywhere

### Mask Errors
✗ Traditional anime kitsune mask with painted features  
✗ Glowing eyes or light emission from sockets  
✗ Expressive face (smiling, frowning, emotion)  
✗ Hair tied up, styled, or colored (must be straight black)

### Silhouette Corruption
✗ Bulky mecha armor, thick robotic limbs  
✗ External cables, wires, tubes, hoses  
✗ Loose mechanical parts dangling  
✗ Muscular body structure or exaggerated proportions  
✗ Sexualized pose or anatomy (oversized chest, suggestive stance)

### Weapon Failures
✗ Curved katana blade  
✗ Thin, elegant sword  
✗ Clean laser/plasma blade aesthetic  
✗ Fantasy ornaments, engravings, decorative elements  
✗ Holographic blade or magic effects

### Material Violations
✗ Porcelain appears rusty or corroded (ceramic doesn't rust)  
✗ Porcelain shattered into loose fragments (cracks intact only)  
✗ Plastic/glossy toy appearance  
✗ Generic robot metal texture  
✗ Dirty, grimy, or weathered porcelain (clean fractures only)

### Color Contamination
✗ Green anywhere on character  
✗ Orange anywhere on character  
✗ Yellow paint (except ultra-thin kintsugi gold seams)  
✗ Cyan/teal painted on armor (Empire color, environment only)  
✗ Rainbow neon or saturated multi-color glow

### Lighting Failures
✗ Flat even lighting, no shadows  
✗ Unmotivated floating rim lights  
✗ Magic auras or fantasy glows without physical heat source  
✗ 2D flat UI panels overlaying subject  
✗ Bloom/lens flare overuse

### Style Drift
✗ Anime cute/chibi aesthetic  
✗ Superhero bright/colorful tone  
✗ Cyberpunk clutter overload (excessive greebling)  
✗ Waifu/sexy character design  
✗ Parody or comedic treatment  
✗ Generic sci-fi without brutalist discipline

### Technical Issues
✗ Extra limbs, malformed anatomy  
✗ Poorly drawn weapon (bent, transparent, floating)  
✗ Inconsistent scale (blade too small, character too large)  
✗ Deformed structural proportions

---

## CRITICAL REJECTION TRIGGERS

**Instant fail if ANY of these appear:**
- Human face visible
- Curved sword
- Cyan painted on armor
- Anime overstyling
- Bulky mecha design
- External cable clutter

## USAGE PROTOCOL

1. Review output against PASS checklist
2. If ANY item in FAIL section detected → REJECT
3. If ≥90% PASS items present → APPROVE
4. If 70-89% PASS items → REVISE
5. If <70% PASS items → REGENERATE from scratch
