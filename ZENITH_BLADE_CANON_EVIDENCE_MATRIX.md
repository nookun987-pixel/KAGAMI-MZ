# ZENITH_BLADE_CANON_EVIDENCE_MATRIX

Read-only synthesis. Status categories used throughout:
**1. VERIFIED CURRENT RULE** — the latest-dated, non-superseded source states this and nothing later contradicts it.
**2. VERIFIED HISTORICAL RULE** — was true/locked at some point, later superseded or overtaken by process (methodology may still be valid even if the visual FORM was revoked).
**3. OPERATOR-ACCEPTED VISUAL DIRECTION** — an operator explicitly approved a visual result (not just a technical gate).
**4. REJECTED DIRECTION** — an operator explicitly rejected this.
**5. CONFLICT** — two or more sources disagree and neither is cleanly superseded by the other.
**6. UNKNOWN** — no documentary evidence found either way.
